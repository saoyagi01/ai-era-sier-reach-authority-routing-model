# AI時代のSIer組織における射程・権限・経路不整合の概念モデル

生成AIが組織内の主体に与える作用可能範囲の変化を、個別の意思決定単位で分析する概念論文のリポジトリです。

本稿では、次の4つの構成要素を分離します。

- 保有有効射程 C<sup>H</sup>
- 要求射程 C<sup>R</sup>
- 意思決定権 A
- 経路 R

その配置関係から、射程・権限・経路不整合 M を構造条件として診断し、M1～M4の各類型と組織設計上の介入候補を接続します。待ち、再照会、手戻り等はMの定義要素ではなく、独立した結果変数として扱います。

## 主要な内容

1. 個別の意思決定 d を分析単位とする研究デザイン
2. C<sup>H</sup>、C<sup>R</sup>、A、Rの概念境界と作用関係
3. CH/CR/A/Rの四変数を用いた構造状態の診断
4. M1～M4の不整合類型と介入候補
5. P1・P2・P4の中核命題と、P3のSIer文脈における応用命題
6. CH/CRの要求項目プロファイルによる操作化
7. CH・A・Rの実証上のコーディング境界
8. 本番変更事例によるCR→CH/S→A→R→M→介入候補→結果観測の適用例
9. 評価者間一致、構成概念妥当性、外的妥当性を含む将来の測定計画

## 公開・利用上の注意

- 本稿は概念研究であり、P1～P4、M分類、介入候補の効果はまだ実証していません。
- Mは構造診断であり、待ち時間、再照会、手戻り等の結果変数とは分離されます。
- AIは重要な技術変化条件ですが、理論成立の唯一条件ではありません。
- 軍事事例は概念抽出のための限定的参照であり、SIerへの実証証拠ではありません。
